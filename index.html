📖 How to Play

  1. Fill the empty squares using numbers 1 to 9.
  2. Each row must contain numbers without repetition.
  3. Each column must contain numbers without repetition.
  4. Each 3×3 box must contain numbers without repetition.
  5. Use Notes to remember possible numbers.
  6. Use Hint when you need help.

♿ Accessibility Features

High contrast mode, larger numbers, voice assistance, simple controls, and beginner-friendly instructions.
